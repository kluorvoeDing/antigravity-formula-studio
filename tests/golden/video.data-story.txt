# 任務
請製作一段可以在瀏覽器播放的動態影片。
本文件是完整規格。請一次做完整支影片，不要只給分鏡表、片段或示意。
規格沒寫到的地方，不要停下來發問；請自行做出合理的決定，並在交付時以「我的假設」為標題逐條列出。
各項要求若互相牴觸，排在前面的優先：禁止事項、影片類型、規格、視覺風格、動態與轉場、個別分段。取捨的結果請一併列入「我的假設」。

## 影片定位
- 影片類型：數據動畫（Data Animation）——全片只講一個結論。前約 15% 顯示問題與座標軸，中段約 55% 讓數字與圖形從零依序生長到終值，每次只新增一組資料並標出數值，最後約 30% 停在一句結論與資料來源。同一畫面最多 5 個數據點。

## 規格
- 橫式 16:9（Landscape 16:9）：畫面比例固定 16:9。重要文字與主體放在中央 90% 的範圍內，四邊各留 5% 空白；主標題字級不小於畫面高度的 6%，說明文字不小於 3.5%。可左右分區放文字與主體，同一畫面最多兩個視覺焦點。
- 60 秒（60-Second Video）：全片總長 60 秒：前 5 秒內要讓觀眾看懂主題，最後 5 秒留給收尾畫面；中間依影片類型與分段分配時間，每段至少 4 秒，並在中段安排至少兩次較慢的停頓讓觀眾消化。

## 分段腳本
### 分段（依此順序播放）
1. 標題卡（Title Card）：約佔全片 8%：畫面只放片名一行與副標一行，其餘留白。文字在 0.4 秒內完成進場，之後完整停留至少 1.5 秒再離場。片名不超過 12 個字，副標不超過 20 個字，兩者字級至少相差一倍。
2. 痛點段（Problem Beat）：約佔全片 15%：用一個具體情境呈現麻煩，畫面要有明顯的「不對勁」，例如雜亂、重複或一直在等待，並附一行不超過 14 字的描述。段落結尾讓這個畫面被清空或換掉，作為轉折，帶入解決方式。
3. 數據段（Stat Callout）：約佔全片 12%：全畫面只放一個大數字與一行說明，數字在 1 秒內從 0 累加到終值，之後靜止至少 1.5 秒。若有第二個數字，換新畫面呈現，不併排。數字旁標明單位，並註明來源或標示「示意」。
4. 結尾卡與號召（End Card）：約佔全片 10%：停在最後一個靜止畫面，由上而下放品牌名稱、一句不超過 16 字的行動呼籲與一個去處（網址或帳號）。三者進場後完整停留至少 2 秒，其間不再有新元素進入，最後一格仍保留完整內容，不淡出成空白。

## 視覺
- 深色科技（Dark Tech Aesthetic）：背景用接近黑色的深色，主要文字用高亮度的淺色，強調處用一個亮色。標題用無襯線字體，數據與標籤用等寬字體。背景可加透明度低於 10% 的細格線。發光效果只用在一到兩個重點物件上，不要整個畫面都在發光。
- 黑白加一個強調色（Monochrome + Accent）：背景用淺灰白 #fafafa 約 60%，文字與圖形用近黑 #111111 約 25%，輔助用中灰 #8a8a8a 約 5%，強調色用橘紅 #ff4f1f，面積不超過 10%。強調色每個畫面只用在最重要的一個元素上。文字與背景對比至少 7:1。

## 動態與轉場
- 指數減速（Exponential Ease-Out）：預設使用指數減速曲線（cubic-bezier(0.16, 1, 0.3, 1)）：進場 600 毫秒，前 30% 的時間走完約八成距離，尾端緩緩停住；離場 300 毫秒，使用加速曲線。個別技法另有規定時以該技法為準。
- 劃接（Wipe Transition）：段落之間用劃接：新畫面以直線邊緣的遮罩由左向右揭開，時長 450 毫秒、使用先快後慢的曲線；揭開期間舊畫面保持不動，轉場結束後的前 0.3 秒內不安排新動作。
- 描線動畫（Line Drawing Animation）：用 SVG 路徑做描線：線條在 1.2 秒內由起點畫到終點（stroke-dashoffset 由路徑長度減到 0），線寬固定；畫完後 300 毫秒內填入色塊或文字，多條線依序延遲 150 毫秒開始。
- 圖表生長（Animated Chart Build）：圖表在 1.5 秒內生長：長條由基線向上長高、折線由左向右畫出、圓餅由 12 點鐘方向順時針展開，各項依序延遲 100 毫秒；數字同步由 0 累加到目標值，完成後停留至少 1.5 秒。

## 聲音與字幕
- 旁白稿與時間碼（Voiceover Script）：寫出完整旁白稿並標上時間碼：每句附開始與結束秒數，語速約每秒 4 個中文字；同一句同步以字幕顯示，畫面關鍵元素在旁白提到它之後 200 毫秒內出現。若有音檔，附上檔名與放置方式，缺檔時只顯示字幕。

## 技術與交付
- 單檔 HTML 動畫（Single-File HTML Animation）：成品是單一 HTML 檔：CSS 與 JavaScript 都寫在檔內，不需建置、離線可開，字體使用系統字體堆疊。以 requestAnimationFrame 讀取目前播放時間來換算每個元素的狀態；開啟頁面即自動播放，結束後停在最後一格。
- 播放控制列（Playback Controls）：在畫面下方放一條播放控制列：播放與暫停按鈕、重新播放按鈕、目前時間與總長（mm:ss）；空白鍵切換播放與暫停，按 H 鍵可隱藏控制列。控制列不得遮住字幕的安全範圍。
- 可跳到指定時間（Seekable Timeline）：加入可拖曳的進度條：拖曳或點擊可跳到任意時間，畫面立即呈現該時間點的狀態（元素位置、文字與透明度都由時間算出）；方向鍵左右各跳 1 秒，並在進度條上標出每個分段的起點。
- 整支影片由同一條時間軸驅動：每個畫面只由播放時間決定，不依賴載入速度、捲動或隨機數，重新播放的結果完全相同。
- 訪客設定減少動態（prefers-reduced-motion）時，改為依序淡入淡出的版本，總長度不變。
- 交付方式：若你能在工作目錄建立檔案，請直接建立，完成後列出檔案清單與開啟方式；若不能，請逐一以程式碼區塊輸出每個檔案的完整內容（預設只有一個 HTML 檔），並在每個區塊的前一行標明檔名。不得省略任何部分，也不得以「其餘相同」帶過。

## 畫面文字
- 字幕與畫面文字語言：繁體中文（台灣用語）
- 依本規格寫出具體的畫面文字，不得使用 Lorem ipsum 或「標題文字」這類佔位字。數據、客戶名稱與見證若沒有提供，一律明確標示為「示意」。

## 禁止事項
- 禁用藍紫漸層（No Purple-Blue Gradients）：全片不得使用藍色到紫色的漸層，也不得使用漸層文字、發光光暈球與霓虹描邊。背景使用純色；需要層次時改用明度不同的同色系色塊、位置與大小的對比，或留白。
- 禁止文字停留太短（No Unreadable Text）：全片每段畫面文字完整顯示後，停留時間至少為「字數乘 0.15 秒再加 0.8 秒」，最短 1.5 秒；文字進場動畫結束後才開始計時，且文字與背景的對比至少 4.5:1。文字動畫尚未結束前不得換景。
- 禁止捏造數據（No Fabricated Data）：全片不得自己編造數字、百分比、客戶名稱或用戶評價。沒有提供時，畫面上以「示意」標示，並使用明顯的假資料，例如 100、50、25，不得使用看似真實的精確數字，例如 87.3%。

## 驗收清單
交付前請逐項自我檢查，全部符合才算完成：
- [ ] 全片只有一個結論；每個數據點都標有數值；結尾畫面有資料來源或標明「示意」。
- [ ] 畫面比例為 16:9；所有文字距邊緣至少 5%；主標題高度不小於畫面高度的 6%。
- [ ] 總長 60 秒，誤差在 0.5 秒內；前 5 秒就看得出主題；中段至少有兩次節奏放慢的段落。
- [ ] 標題卡只有片名與副標兩行文字；文字完整停留至少 1.5 秒；片名不超過 12 個字。
- [ ] 有一個具體情境畫面與一行不超過 14 字的描述；段落結尾畫面被清空或換掉。
- [ ] 每個畫面只有一個大數字與一行說明；數字旁有單位與來源或「示意」標示。
- [ ] 最後畫面有品牌名稱、行動呼籲與去處；三者完整停留至少 2 秒；最後一格不是空白。
- [ ] 背景為深色；數據與標籤使用等寬字體；發光物件在同一畫面不超過兩個。
- [ ] 畫面只有黑、白、灰與一個強調色；強調色面積不超過 10%，每個畫面只用在一個重點元素。
- [ ] 進場時前段移動明顯較快、尾段緩慢收住，沒有回彈。
- [ ] 轉場時有一條清楚的直線邊緣由左向右掃過，舊畫面在其後被取代。
- [ ] 線條由起點逐漸延伸到終點，畫完後才出現填色。
- [ ] 圖表由空白逐步長成，數字同步累加，結束後靜止至少 1.5 秒。
- [ ] 每句旁白都有開始與結束秒數，並對應一句字幕與一個畫面元素。
- [ ] 只有一個 .html 檔，離線雙擊就能自動播放，結束後停在最後一格。
- [ ] 控制列有播放、暫停與重播，空白鍵可暫停，按 H 後控制列消失。
- [ ] 拖曳進度條到任一時間點，畫面與正常播放到該時間時完全相同。
- [ ] 任何時間點的畫面都沒有藍紫漸層、漸層文字或模糊的發光光暈。
- [ ] 每段文字完整顯示後至少停留 1.5 秒，且動畫結束前沒有被換景切走。
- [ ] 每個數字都來自提供的素材，或標有「示意」且為整數示例值。
- [ ] 「分段腳本」列出的每一段都已實作，順序一致，沒有以註解或「待補」帶過的段落。
- [ ] 從頭播放到結束的總長度符合「規格」的片長，誤差在 0.5 秒以內。
- [ ] 重新整理後再播放一次，每個時間點的畫面都和第一次相同。
- [ ] 瀏覽器主控台沒有錯誤訊息。
- [ ] 「禁止事項」中的每一項都沒有出現。
- [ ] 交付內容的最後附有「我的假設」清單。
