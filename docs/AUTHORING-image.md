# 圖片生成模組：撰寫補充規範

先讀 `docs/AUTHORING.md`，再讀這份。範本在 `data/image/template.js`，模組清單在 `docs/image-module-roster.md`。

## 這個主題的 prompt 不是句子，是短語

提示詞是一份分行標籤的畫面規格，例如：

```
構圖：中景，人物腰部以上入鏡；主體放在右側三分線，左側留白放標題
光線與鏡頭：清晨窗邊柔光從左側斜射，陰影柔和；85mm 人像鏡頭，背景柔焦
```

同一個標籤底下的模組會用全形分號「；」接成一行，所以：

- `prompt` 是 **8–90 字的短語**，不是完整句子。結尾**不要**加句號。
- 寫「畫面上要看到什麼」，具體到能畫出來：方向、比例、距離、材質、色碼或色名。
- 不要寫「請生成」「這張圖要」這類開頭；不要提到別的標籤管的事（構圖不提光線，風格不提比例）。
- 想要寫實就寫明「真實照片質感」；鏡頭參數只是外觀提示。
- 畫面文字：要出現的字由使用者另外提供，模組只描述「怎麼呈現」（字體風格、位置、只出現一次、不要多餘文字）。
- 「避免」類用直接的否定短語即可（官方範例就是這樣寫，例如「不要浮水印、標誌與商標」）。
- 不寫 `accept`（這個主題沒有驗收清單）。

## 預覽

- 構圖、比例類用 `frame`：`{ kind: "frame", ratio: "16:9", shot: "medium", place: "right", grid: true, text: "left" }`，合法值見 `data/schema.js` 的 `FRAME`。`shot` 的 `object`／`objects` 用在商品與平鋪。
- 色彩類用 `palette`（格式看 `data/web/07-color.js`）。
- 其他類別沒有合適預覽就不加。

## 標籤

只能用 `data/schema.js` 的 `TAGS`，例如：構圖、鏡頭、光線、材質、攝影、規格、插畫、圖片、文字、中文、入門、進階、行銷。
