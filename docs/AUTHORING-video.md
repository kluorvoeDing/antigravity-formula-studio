# 動態影片模組：撰寫補充規範

先讀 `docs/AUTHORING.md`（通用規則全部適用），再讀這份。範本在 `data/video/template.js`，模組清單在 `docs/video-module-roster.md`。

## 這個主題的提示詞是給誰的

提示詞會貼給任何會寫程式的 AI。預設成品是**單一 HTML 檔的動畫**：一條固定時間軸、在瀏覽器打開就會播放。所以 `prompt` 要寫成「怎麼在畫面上做出來」的指示，而且要用秒數與時間點量化：

- 好：「每段標題在 0.4 秒內由遮罩下方滑入，停留至少 1.2 秒再離場；同一段內的元素依序延遲 80 毫秒。」
- 不好：「營造震撼的開場氣勢。」

## 各類別要注意的事

- **影片類型**：說明這種片的節奏分配與畫面重點（例如前 3 秒要出現什麼、哪一段佔最長），不要指定配色、字體或片長。
- **規格**：比例模組交代構圖重點（字級下限、主體位置、字幕安全範圍）；片長模組交代各段大約如何分配秒數。兩者互不提及。
- **分段結構**：每段寫出「這段畫面上有什麼、大約幾秒、怎麼進出場」。秒數用「約佔全片 N%」表示，不要寫死秒數，因為片長由規格決定。
- **視覺風格／配色**：可以談整體美學、字體類型、色彩用法；配色模組給出具體色碼建議與用法比例。不要規定動畫時長。
- **動態與轉場**：只管動作本身（曲線、時長、方向、延遲）。緩動模組描述預設值，並寫明「個別技法另有規定時以該技法為準」。
- **聲音**：成品是瀏覽器裡的動畫，不一定能產生音檔。寫成「在時間軸上標出音樂重拍／旁白的時間點，並以字幕或畫面元素對齊」這類做得到的事；需要音檔時要求附上檔名與放置方式。
- **技術與交付**：`html-timeline` 是預設（單一 HTML 檔、不需建置、離線可開）。`html-plus-mp4` 是進階：除了 HTML，還要附上把動畫錄成 MP4 的做法（例如逐格擷取再合成），並標 `needs: ["files", "shell"]`。
- **禁令**：全片規則，可以用「全片不得」。

## 預覽

沒有適合的預覽就不要加（卡片會顯示 `note`；沒有 note 就留白）。可用的預覽：

- `frame`：畫面比例與主體位置，適合規格類。規格：`{ kind: "frame", ratio: "16:9", shot: "medium", place: "center", grid: false, text: "none" }`，合法值見 `data/schema.js` 的 `FRAME`。
- `motion`：既有的具名動畫，`{ kind: "motion", name: "text-reveal" }`，合法值見 `MOTION_NAMES`，只能挑意思相近的。
- `palette`：配色模組用，格式看 `data/web/07-color.js`。
- `type`：字體相關，格式看 `data/web/06-typography.js`。
- `versus`、`copy`：格式看 `data/web/13-voice.js` 與 `14-anti-slop.js`。

## 標籤

除了原本的 `TAGS`，這個主題可用：構圖、鏡頭、運鏡、光線、材質、攝影、節奏、聲音、字幕、後製、敘事結構、規格、一致性。
