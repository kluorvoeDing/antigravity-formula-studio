# 任務
請製作一個完整的網站。
本文件是完整規格。請一次完成全部內容，不要只給大綱、片段或示意。
規格沒寫到的地方，不要停下來發問；請自行做出合理的決定，並在交付時以「我的假設」為標題逐條列出。
各項要求若互相牴觸，排在前面的優先：個人風格、禁止事項、網站類型、視覺風格、色彩與字體與形狀、整體版型、個別區塊與元件。取捨的結果請一併列入「我的假設」。

## 定位與受眾
- 網站類型：單一用途小工具（Online Tool）——這是一個單一用途的線上工具，目的是讓使用者打開頁面就立刻完成一件事，不需註冊。輸入區放在首屏最顯眼的位置，輸入後即時或一鍵產生結果，結果可直接複製或下載；使用說明與常見問題放在工具下方，不得擋在工具前面。

## 頁面結構
### 整體版型
- 單欄置中（Single-Column Layout）：採單欄置中版型：各區塊由上到下依序堆疊、水平置中，不使用側欄，區塊之間保留一致的垂直間距。只有連續的長文段落限制行寬在 720px 以內；卡片列、圖片與表格等區塊不受此限，可以比段落寬並在區塊內並排分欄。寬度小於 768px 時一律回到單欄。
### 區塊（由上到下，依此順序）
1. 步驟說明（How It Works）：以區塊標題開頭，下方橫向排 3 到 4 個步驟，每步依序是步驟編號、一個圖示、不超過 8 字且以動詞開頭的標題與一句不超過 30 字的說明，步驟之間以線條或箭頭表示先後。最後一步之後放一個開始使用的按鈕。寬度小於 768px 時改為由上往下排列，連接線改為垂直。
2. 常見問題摺疊清單（FAQ Accordion）：列出 6 到 8 個常見問題，以摺疊清單呈現：每列顯示問題與一個展開指示圖示，點擊後在下方展開答案、圖示隨狀態改變，再點一次收合。預設展開第一題。每個問題用按鈕實作，可用 Tab 移動、Enter 或空白鍵切換，並設定 aria-expanded 與 aria-controls。
3. 極簡頁尾（Minimal Footer）：頁尾只用一列：左側放標誌或品牌名稱與版權年份，右側放 2 到 4 個文字連結（例如隱私權政策、聯絡我們）與最多 4 個社群圖示，與上方內容明確隔開，上下留白保持緊湊。社群圖示要有無障礙名稱。寬度小於 640px 時改為置中的兩行，連結在上、版權在下。
### 元件與互動模式
- 快顯通知（Toast Notification）：操作成功的回饋以快顯通知呈現：一則不超過 20 個字的訊息從畫面右下角滑入，停留 4 秒後自動淡出，滑鼠停在上面時暫停計時。同時出現多則時向上堆疊。訊息必須放在即時播報區域（aria-live="polite"）讓螢幕閱讀器讀出。
- 開關（Toggle Switch）：設定清單中每個二選一的功能用開關呈現：左側是功能名稱與一行說明，右側是開關，點整列或開關本身都能切換，切換後立即生效。狀態不能只靠滑塊位置表示，要同時有「開」「關」文字（使用 role="switch"、aria-checked，空白鍵可切換）。
- 分段控制（Segmented Control）：在內容上方放 2 到 4 段的分段控制，每段等寬、標籤不超過 4 個字，預設選中第一段。點擊後切換同一份資料的呈現方式，不換頁也不重新載入。左右方向鍵移動選取（role="radiogroup" 搭配 role="radio"，選中者 aria-checked="true"）。

## 視覺系統
### 字體排印
- 單一幾何黑體（Single Geometric Sans）：全站只使用一種幾何無襯線字族，以 3 種字重（400、500、700）與一組固定字級階層建立層次。大標題的字距收緊約 -0.02em，小字與標籤的字距略放寬；不使用斜體或第二種字體做強調，強調一律用字重。
### 色彩
- 黑白灰加一個強調色（Monochrome + One Accent）：色彩採中性色加單一強調色：背景、文字、邊框只用黑、白與 4 到 5 階灰；另選一個強調色，只用在主要按鈕、連結、選中狀態與重點數字，面積不超過畫面的 10%。不得出現第二種彩色，成功與錯誤狀態除外。
- 深淺色可切換（Light & Dark Mode Toggle）：同時提供淺色與深色模式：所有顏色以語意化的自訂屬性定義（例如背景、表面、主要文字、次要文字、邊框、強調），兩種模式各給一組值。預設跟隨系統設定（prefers-color-scheme），並提供一個切換按鈕，選擇結果儲存在瀏覽器本機，下次造訪沿用。深色模式的背景用深灰而非純黑。
### 間距與形狀
- 分級圓角（Radius Scale）：圓角採三級階層並以自訂屬性定義：小型元件（按鈕、輸入框、標籤）6px，卡片 12px，大型容器與彈出視窗 20px。巢狀時內層圓角必須小於外層，差值等於兩者之間的內距。不得所有元件共用同一個圓角值。
- 細線分隔（Hairline Borders）：層次只靠邊框表達：卡片、輸入框與區塊分界使用 1px 實線，顏色為比背景略深的中性色；全站不使用任何陰影。浮層（下拉選單、彈出視窗）以稍深的邊框加上不同的底色與背景區分。
### 圖像與媒體
- 線條圖示（Line Icons）：圖示統一使用線條風格的內嵌 SVG：線寬 1.5px、端點與轉角為圓頭、畫在 24px 的格子上，顏色繼承文字顏色（currentColor）。整站只用同一套圖示，不混用填色圖示，也不得以表情符號代替圖示。純裝飾的圖示對輔助科技隱藏，單獨作為按鈕的圖示要有文字標籤。

## 動態與互動
- 克制的動態（Subtle Motion）：動態以回應操作為主：點擊與懸停的過渡預設 150 到 250 毫秒、位移不超過 8px、緩動用減速曲線（ease-out），展開、收合、切換、出現與消失才加動畫，預設不加自動播放的裝飾動態。已選效果另有時長、曲線或減少動態規定時，以該效果為準；訪客設定減少動態（prefers-reduced-motion）時改為立即切換。
- 按壓回饋（Button Press Feedback）：只在按鈕與可點擊的圖示上加按壓回饋：按下時縮小到 96%，時長 80 毫秒，放開後以 150 毫秒減速恢復；縮放不影響周圍版面。觸控與鍵盤（Enter、空白鍵）都要觸發。訪客設定減少動態時改為只加深底色。

## 技術與交付
- 單一 HTML 檔（Single HTML File）：成品是單一 HTML 檔：所有 CSS 寫在 head 的 style 標籤內，所有 JavaScript 寫在 body 結尾的 script 標籤內，不使用任何建置工具或框架。除字體外不得依賴外部檔案；字體可從公開的字體服務載入，但必須指定系統字體作為後備。檔案在沒有伺服器的情況下直接開啟即可完整運作。
- 原生 CSS 與自訂屬性（Plain CSS with Custom Properties）：樣式只使用原生 CSS：在根層級以自訂屬性定義設計變數（顏色、字級、間距、圓角、陰影），其餘樣式一律引用變數而不寫死數值。使用現代版面語法（Grid、Flexbox、clamp()、邏輯屬性），類別名稱以元件為單位命名。不使用任何 CSS 框架或前置處理器。
- 本機儲存（Local Storage Persistence）：使用者的設定與輸入內容儲存在瀏覽器的 localStorage：每次變更後 300 毫秒內寫入，載入頁面時還原。讀寫都要包在錯誤處理中且只在瀏覽器端執行，儲存空間不可用時網站仍能正常運作。儲存的資料帶版本號，並提供一個「清除資料」的操作。
- 交付方式：若你能在工作目錄建立檔案，請直接建立，完成後列出檔案清單與開啟方式；若不能，請逐一以程式碼區塊輸出每個檔案的完整內容，並在每個區塊的前一行標明檔案路徑。不得省略任何部分，也不得以「其餘相同」帶過。
### 品質要求
- 行動優先響應式（Mobile-First Responsive）：以行動優先的方式撰寫樣式：基礎樣式針對 375px 寬的螢幕，再以最小寬度的媒體查詢在 768px 與 1200px 逐步加寬版面。所有寬度下頁面整體都不得出現水平捲軸（容器內刻意的橫向捲動除外）；觸控裝置上的可點擊目標至少 44px 見方；圖片與影片不超出容器。
- 基本無障礙（Accessibility Basics (WCAG AA)）：達到 WCAG 2.2 AA 的基本要求：內文與背景對比至少 4.5:1，大字與介面元件至少 3:1；所有功能可只用鍵盤操作，聚焦時有清楚可見的外框；有意義的圖片有替代文字，裝飾圖片的替代文字留空；表單欄位都有關聯的標籤；不只靠顏色傳達資訊。
- 完整鍵盤操作（Keyboard Navigation）：Tab 順序與畫面閱讀順序一致，不使用大於 0 的 tabindex；頁面第一個可聚焦元素是「跳到主要內容」連結；自訂元件支援對應按鍵：選單與分頁用方向鍵移動，Esc 關閉浮層，Enter 與空白鍵觸發按鈕。焦點不能卡在任何元件裡出不來。
- 觸控目標大小（Touch Target Size）：觸控裝置上所有可點擊目標的點擊範圍至少 44×44px，視覺較小的圖示以內距擴大可點範圍；相鄰目標之間至少留 8px 間距。段落中的行內文字連結不受 44px 限制，其餘目標最低不得小於 WCAG 2.2 規定的 24×24px。

## 內容與文案
- 介面與文案語言：繁體中文（台灣用語）
- 語氣：惜字如金（Minimal Copy）——文案惜字如金：主標題不超過 8 字，每個區塊只保留一個標題與一句不超過 20 字的說明，按鈕文字 2–4 字；能用數字或名詞說清楚的就不寫完整句子。刪除連接詞、客套話與重複說明，不用驚嘆號與問句，但不得刪到讀者看不出產品做什麼。
- 依本規格的定位寫出具體、可直接上線的文案；不得使用 Lorem ipsum 或「標題文字」這類佔位字。素材沒提供的產品細節（功能、價格、日期）可自行合理設定並在「我的假設」中註明；客戶名稱、見證與成果數字若沒有提供，一律明確標示為「示意」。

## 禁止事項
- 禁用藍紫漸層（No Purple-Blue Gradients）：不得使用藍色到紫色的漸層，也不得使用漸層文字、背景光暈球與霓虹發光效果。背景使用純色；需要層次時改用明度不同的同色系色塊或留白。
- 禁用表情符號當圖示（No Emoji as Icons）：不得以表情符號作為圖示、項目符號或標題裝飾。需要圖示的地方使用風格一致的內嵌 SVG；沒有合適圖示時寧可不放。
- 禁用空泛標語（No Filler Copy）：文案不得使用放在任何產品都成立的空泛句子，例如「釋放潛能」「重新定義」「無縫整合」「賦能團隊」「次世代」。每個標題都要包含這個產品特有的對象、動作或數字；把產品名稱換成別的產品後句子仍然成立，就必須重寫。
